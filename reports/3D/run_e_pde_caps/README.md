# run_e 连续 PDE 端面与三维网格规模验证

端面使用 201×201 二维 Winslow 网格（最大 1000 次、容差 1e-10），通过保留四条精确外缘的双三次插值定义连续参数面；不做参数重分布。体网格由六个面构造体 TFI 初值，再实际求解三维 Winslow PDE（最大 1000 次、容差 1e-6）。以下规模均指节点数。

训练外推范围两端为 0.55、1.50；评估参数为 1.52、1.55。每个候选先检查六个规定边界面及共享边，再检查求解收敛、所有体单元的角点 Scaled Jacobian、翻转和退化。未通过边界面的案例不继续体求解。局部体单元检查不是任意三维网格全局无重叠的数学证明。

## 选择建议

推荐 **61×21×11**：在上述四个参数下均收敛，且翻转、退化单元均为 0，总计 12000 个六面体。体网格求解约 11–13 秒，端面构造另需约 3 秒（本地 CPU 单任务实测，不能直接当作服务器耗时）。

**51×51×11** 同样通过四个端点，最差 Scaled Jacobian 的余量较大，但有 25000 个六面体，体求解约 60–70 秒。如果优先考虑 x、y 节点数一致和单元质量余量，可选择它；若优先考虑数据生成成本，选择 61×21×11。

不推荐 21×21×11：深度 1.50、1.52 的端面虽合法，三维 PDE 求解之后仍各有 20 个翻转单元；1.55 的端面本身不合法。单纯提高一个方向的节点数也不保证质量单调改善，采样位置相对于圆弧的位置会影响粗单元。

**验证范围**：本报告没有声称已经生成全部 500 个样本，也未证明任意中间参数都合法。正常数据生成仍保留每个样本的规定边界面检查、首尾 PDE 体网格检查及生成后警告机制。未修改其他边界。

## 复现与生成

```powershell
python scripts/data/check_run_e_grids.py --grids 21x21x11 61x21x11 51x51x11 --values 0.55 1.50 1.52 1.55
python src/data/generation/make_dataset_parametric_3d.py --family run_e --split extrapolation --version 2 --size 500 --grid-shape 61x21x11 --parameter-range 0.55 1.50 --workers 4 --winslow-max-iter 1000 --winslow-tolerance 1e-6 --timing-samples 3 --output-root data/raw/3D
```

新数据集名称为 `run_e_ext_2_500_61_21_11`。版本 2 表示端面定义变化，不是训练 run-tag；旧版数据、训练和评估结果不改名、不覆盖。新数据需要重新训练，不能直接套用旧端面训练的 HMONet。

目前保留登记的统一默认 11×21×11；上述命令明确覆盖为推荐规模。因此不要将无参数全族批量生成当作已采用推荐 run_e 规模。评估配置已登记新版本的 61×21×11 和 51×51×11 两种数据集。

`boundary_screen.json` 保存更多规模的端面初筛，仅表示端面合法性；`grid_validation.json` 保存上表对应的实际三维 PDE 求解结果。

连续面插值系数在 `geometry.json` 中只存一份。HMONet 加载后直接求值，无需训练期间重新求解二维 PDE；另两个网络的输入边界点从同一面采样，传统方法在评估中也使用相同定义。

补充检查：训练区间内部参数 `0.65、0.75、0.85、0.95、1.05、1.15、1.25、1.35、1.40、1.45` 的两种候选规模均通过六面检查。这里仅补查边界面，未将其混写为完整三维体求解结果。原始记录见 `interior_parameter_face_checks.json`。

## 集成核验

- 使用正式生成入口、两个并行 CPU worker，实际生成 `61×21×11`、深度 `0.55/1.50` 的两样本临时数据集；两者三维 PDE 均收敛，非法单元数均为 0。
- 从磁盘加载保存的连续面时禁用端面 PDE 构造，仍可成功读取；说明训练加载不会重复求解端面。
- 评估配置重新构造的两个边界与保存的边界节点最大差均为 `0.0`（本地 float64 比较）。
- 项目回归命令 `python -m pytest -m "not slow" -q`：415 passed，1 deselected。覆盖 NumPy/Torch 求值一致性、float32/float64、HMONet 精确边界、三个模型反向传播和数据集读写。
