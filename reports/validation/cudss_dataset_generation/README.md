# 三维数据生成：cuDSS 与 CPU 一致性核验

CPU 保留原 SciPy 直接求解。GPU 仅替换线性求解后端，采用 cuDSS 0.4 一般非对称直接分解；矩阵/RHS 组装、初值、边界处理、外层更新及收敛条件共用原 CPU 代码。端面固定边界消元，体网格保留边界单位行；每次 GPU 分解供所有坐标 RHS 共用。旧 BiCGSTAB 实现已移除。

## 验证范围与结果

- 33 项相关 pytest 测试通过（真实 CUDA、CPU 对照、spawn 保存读取、队列模拟、参数面和生成入口回归）。本机 Windows、RTX 4050 Laptop、PyTorch 2.5.1 / CUDA 12.1、cuDSS 0.4.0.2。
- 九类边界分别取外推训练区间上端一个样本，独立 201×201 端面及默认体网格：全部收敛，局部 Jacobian/退化单元检查均为零非法单元。这不是整个 500 样本数据集或所有评估参数的合法性保证，也不是全局相交的数学证明。
- 九样本体求解最大原系统相对线性残差：4.8814e-12。
- swb_a 参数 0.04、0.30，体网格 5×7×5、端面 201×201，CPU/GPU 体网格最大差 5.0627e-14，连续面 23×19 查询最大差 1.8419e-13；外层迭代次数分别均为 2、4，局部质量检查一致。
- 文档 36 条单类命令及 6 条批量命令均经过参数解析检查（不实际生成整套数据）。
- 只有一张物理 GPU；真实多 GPU / Linux 运行未实测，多 GPU 分配由双设备队列模拟覆盖。记录的样本耗时仅为功能检查用时，不是受控性能基准。
