# 三维 GPU 数据集生成验证

CPU 默认实现保留；GPU 为显式可选后端。以下为单张 RTX 4050 Laptop GPU 的功能检查，不是服务器多卡性能评测。

## 数值与流程验证

- 33项相关pytest测试通过，包含CPU/GPU离散格式对照、真实spawn子进程生成与数据读取、两设备队列模拟、失败退出、CPU生成和参数面回归。
- 九类均使用201×201独立端面与默认体网格规模，测试外推训练区间上端的一个样本。
- 全部9个样本的PDE迭代收敛，局部六面体Jacobian/退化检查未检出非法体单元；不代表全部500个参数或所有评估参数均合法。
- swb_a两个样本在5×7×5体网格上的CPU/GPU最大坐标差为1.304e-10，连续面加密查询最大差为1.312e-10；保存后均通过数据读取一致性校验。
- 本机只有一张GPU。真实多卡以及Linux服务器运行尚未实测；多设备分配由队列模拟测试覆盖。

## 性能与使用限制

GPU后端使用float64和Jacobi预条件BiCGSTAB，CPU保留SciPy稀疏直接求解。小网格及本机显卡上的GPU实现不保证更快；本次swb_a两个小样本GPU耗时约6.84/12.80秒，CPU工作进程中约2.53/3.87秒。这些时间包含端面构造等工作，不应据此推算服务器多卡倍速。
GPU模式的端面与体PDE在GPU上计算；几何构造、样条拟合、合法性审计和最终写盘仍在CPU完成。未改变参数面定义、混合导数离散或边界固定规则。
内层线性系统未满足残差要求时明确报错，不能把未求解成功的结果伪装成收敛标签。Ctrl+C或任务异常终止本队列子进程。
完整命令见[data/3D/generation_commands.md](../../../data/3D/generation_commands.md)。
