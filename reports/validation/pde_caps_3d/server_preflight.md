## 边界表示与一致性

1. 上下端面各自求解二维 Winslow 网格；连续参数面由精确边界 Coons 面加三次样条位移构成，位移在四条边上为零。两端分别求解，没有上下端面复用，也没有参数重分布。
2. 四侧面保留原始解析几何。其原单位矩形参数域中的 TFI 是恒等映射，不将曲面替换为四棱边构造的空间 Coons 面。
3. 数据集保存端面控制系数、节点向量、原始曲面和求解诊断；读取与训练不重新求端面 PDE。
4. 连续面取样、boundary_samples 和 PDE 标签上的边界节点由读入一致性检查约束。三个网络及 TFI/PDE 评估使用同一几何定义。
5. 九类真实 201×201 端面序列化恢复后的 NumPy/Torch float64 求值最大差为 8.88e-16，查询坐标梯度有限。HMONet float32 硬边界输出与精确面最大坐标差在本次未充分训练模型中不超过 1.24e-6；这是有限精度实现的实测值，不应将浮点实现写成逐位相等。
6. teb_b 外轮廓是按四条矩形直边进行分段线性参数化，已含针对四边中点的测试；不再采用矩形射线相交参数化。其一轮训练流程正常，不构成长时间训练不退化的证明。

## run_e 的例外不能忽略

按用户指定保留默认 41×41×11，没有改回 61×21×11。

| Depth | PDE converged | Flipped volume cells | Minimum scaled Jacobian | Cap issue |
|---|---|---|---|---|
| 0.55 | Yes | 0 | 0.250974 | None detected |
| 1.50 | Yes | 0 | 0.008733 | None detected |
| 1.52 | Yes | 16 | -0.000914 | None detected in prior face check |
| 1.55 | Yes | 20 | -0.015184 | Two concave quadrilaterals on each cap |

1.52 和 1.55 本次直接调用正式评估的 PDE 求解路径，均在 7 次迭代后满足当前停止条件，边界节点改动量为 0，但网格仍有翻转单元。评估完成不能代替质量判断。固定端面中已有的凹四边形不能由 HMONet 内部预测修复；也不能把凹单元直接描述为自相交单元。

此前 61×21×11 在上述端点通过的记录仍有效。训练规模和评估规模可不同；若正式结果需要合法参考网格，应单独选择通过合法性检查的评估规模，或先解决当前粗网格离散问题，而不是通过放宽检测阈值隐藏缺陷。
