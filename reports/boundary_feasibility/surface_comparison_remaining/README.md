# 剩余五类参数面质量和训练耗时，以及九类 HMONet 推理耗时

测试日期：2026-11-23。生产代码、正式配置、数据集和训练模型未修改。仅使用独立离线原型。

## 范围与口径

补测 cah_t、bad_a、lad_a、srt_r、sad_c；分别采用默认外推评估上限 0.38、105°、0.20、0.96、1.42。原方案指当前解析/TFI 式参数面，并非将所有曲面自由替换为四边 TFI 曲面。新方案与上次一致：平面二维 Winslow；弯曲面在原几何上求调和坐标并反解连续参数映射。插值构造网格为 101×101，精确棱边保持不变。

质量来自传统三维 Winslow 网格，不是重新训练 HMONet 的预测。两种参数面采用同一体求解器、相同规模（11×21×11 和 21×21×11 节点），最大 1000 次，收敛相对更新阈值 1e-7；20 次均达到停止条件。边界层指向内第一层或前两层索引单元，O-grid 切缝不是物理边界。所测体网格翻转和退化计数均为零；未声称完成非相邻体单元全局相交证明。

端面图均采用 21×21 个节点，左列原方案、右列 PDE，上下分别 z_min/z_max。倾斜端面投影到各自平面；同一行两列使用同一正交投影和坐标范围，红线为物理边界。

## 训练计时

RTX 4050 Laptop、float32，模型输入 11×21×11，400 个均匀随机中心点，0.01 中心差分，每点 19 个模板查询。每个 batch 循环包含本类训练端点和评估参数。预热 3 次、记录 10 次，交替顺序、GPU 同步墙钟计时。包括清梯度、前向、归一化 PDE、反向、裁剪及 Adam 更新；不包含数据读取、定期全网格 MSE 和一次性参数面求解。这里一次训练是一个 mini-batch，不是 epoch。

使用与上次一致的等价棱边快捷求值（恒零插值直接取原棱边），本次五类完整输出、损失与网络参数梯度最大差均为 0。NumPy/float64 Torch 参数面求值最大差小于 1e-15。

## 九类完整网格推理

相同 HMONet 架构和权重，参数量 415,215，batch=1、float32、输入 11×21×11。输出 21×41×21（18081 节点）和 41×81×41（136161 节点）完整网格，不分块。前向包含 branch、trunk 和 CCAP；模型/参数面已加载，插值系数已预热。排除参数面生成、GPU 到 CPU 拷贝、网格质量及画图。使用未训练权重仅测计算延迟，不据此比较预测精度。

每组预热 5 次、记录 30 次并交替新旧方案。run_e 大规模和 lad_a 小规模初测波动较大，追加 60 次，并将全部 90 次合并统计，没有丢弃初测值。原始样本、标准差和中位数均保留在 JSON。

run_e 单独采用旧 Coons/TFI 端面与当前 201×201 PDE 插值端面（只更换端面）；其他八类采用上述 101×101 分面方案。因此 run_e 开销差较小不代表九类插值工作量完全相同。

## 综合判断

- lad_a=0.20：21×21×11 的边界前两层平均/最差 Scaled Jacobian 分别提高约 5.75%/5.64%，值得进一步小规模训练验证；最差最大角并未改善，不能宣称所有指标均提高。
- cah_t=0.38：前两层平均提高约 2.06%，最差降低约 0.08%，主要收益在平均体单元质量；端面的平均质量反而下降。
- bad_a=105°：平均/最差 Scaled Jacobian 均略降，原参数面已经接近正交，没有替换依据。
- srt_r=0.96：平均提高约 1.43%，最差不变；最小角的最差值从约 10.88° 提高到 31.07°。值得按关注指标权衡，但较低最差 Scaled Jacobian 仍受出口几何角点约束。
- sad_c=1.42：平均提高约 3.06%，最差从 0.08917 降到 0.02911（约 -67.36%）；不建议按当前方案直接替换。
- 联合前次三个测试，优先考虑 teb_b、lad_a 的后续受控训练；其他边界不建议全面替换。run_e 的 PDE 端面是为解决原端面合法性问题，理由不同。
- 延迟增加并不等价于总收敛时间增加相同比例。本次未训练到收敛，也没有确定改变边界参数化后 HMONet 的最终误差。
