# FCA 120° 加密与八类三维 PDE 参数面离线可行性检查

## FCA 120°

使用项目的 float64 二维 Winslow 求解器，最大 1000 次，更新相对误差停止阈值 1e-10，当前精确四段圆弧和默认初始化。所有规模均收敛。

行列式是相邻物理边向量的叉积，未除计算坐标步长，不用于比较不同分辨率的归一化质量。凸单元重叠计数均为零；原审计函数不对非凸单元宣称完整全局重叠证明。

101×101 的四个非法单元分别位于四个逻辑角。圆弧拼接处物理内角为 90°+120°=210°；边界折线对应的单元内角为 208.8°。这是凹单元而非对边交叉的蝴蝶结单元。角点 Jacobian 为负，双线性四边形单元映射不合法。加密无法消除固定逻辑角承受大于 180° 内角这一结构问题。401×401 还出现四个紧邻角点区域的负角点 Jacobian 单元。

## 八类三维边界

检查训练外推区间两端和默认外推评估值，去重后 31 组几何，共 186 个逻辑面（包括 O-grid 切缝面）。不生成三维体网格，不进行模型训练。

采用按面分类的两种方案：

1. 平面面片：投影到自身平面，使用项目二维 Winslow 求解器求 101×101 网格，再插值相对原面映射的位移，四边位移固定为零。使用 201×201 再采样检查，100 个面全部通过。
2. 非平面面片：在原曲面三角网格上用 P1 FEM 求解两个 Laplace–Beltrami 调和坐标，四边参数固定；数值反解坐标映射，用三次插值获得连续参数变换，再复合原解析曲面 S(u,v)。这是离线原型，不是已有生产功能。使用 101×101 求解、401×401 检查，86 个面全部通过。检查了参数映射有向 Jacobian、参数越界、物理单元翻转、局部对边相交及退化；检测计数均为零。

初步尝试把同一 FEM 方案用于所有面时，61×61 下薄翼型端面和圆/椭圆端面出现离散或插值折叠，因此不建议把所有面不加区分地交给同一个插值流程。最终上述结论针对平面/曲面分别处理的方案。

同时将所得面采样到体网格 11×21×11 对应的面尺度（x 面 21×11、y 面 11×11、z 面 11×21），186 个面的局部翻转、自交、退化计数均为零。

结论：八类边界均通过本次数值可行性检查，但不能把 run_e 的平面端面方法原样用于弯曲侧面。弯曲面必须受原几何约束；仅用四条边自由求解三个物理坐标可能改变曲面。连续映射不折叠检查是有限采样验证，不是所有参数、所有点的严格证明；没有验证整个参数区间的所有三维 PDE 体网格。新参数化会改变面内采样点，若以后正式采用，必须统一数据集、三个模型和传统方法的边界表示，并重新生成对应数据集。

相关方法依据：Schmidt & Singh, Approximate Conformal Parameterization of Point-Sampled Surfaces，https://ftp.cs.toronto.edu/csrg-technical-reports/605/PointSetParam09.pdf 。
