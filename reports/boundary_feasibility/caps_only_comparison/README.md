# 三维边界仅端面 PDE 参数化：质量与运行成本离线对比

测试日期：2026-11-23。正式代码、默认配置与数据集均未修改。

## 结论

八类边界均可以只替换两个端面，并保持四个侧面原参数化。十二条共享棱边同时保留原坐标和原参数，测试的最大拼接偏差为 3.674e-16。复杂侧面并不必然需要重新参数化，应由最差质量是否改善决定。

优先考虑 teb_b、lad_a 的仅端面方案；cah_t、swb_a、srt_r、sad_c、tbp_a 的仅端面方案主要提高平均质量，是否值得增加成本需要后续训练验证。bad_a 最差 scaled Jacobian 下降，不建议默认替换。sad_c 六面处理明显降低最差质量，建议保留原侧面。

## 测试范围与限制

质量：每类最大外推评估参数，11×21×11 与 21×21×11 两种体网格；端面使用 101×101 稠密二维 PDE 网格构造连续参数面。内部全部由三维 Winslow PDE 求解，最大迭代1000、相对差收敛阈值1e-7。原参数化与六面处理质量数据复用此前相同设置的缓存；仅端面及选择性侧面版本为本次新求解。

边界附近定义为任一物理边界向内第一层、前两层体单元的并集，并非固定物理距离；O-grid 的切缝不计作物理边界。所有52个组合均收敛，所检查的翻转、退化体单元数为0；离散面网格翻转/单元自交检测也为0。这不等价于证明连续映射在全部参数范围内双射，也未进行所有不相邻体单元的全局相交检测。

这些是 PDE 体网格质量，不是重新训练 HMONet 后的预测质量。当前未进行完整训练，不能据此推断最终误差或总收敛时间。

计时：NVIDIA GeForce RTX 4050 Laptop GPU，float32，HMONet 415215 参数，边界输入网格11×21×11。训练使用400个中心、0.01中心差分、每点19个模板查询，仅归一化PDE损失，包含前向、反向、梯度裁剪与Adam更新；batch=8/64各预热3次，测10次。几何批次混合训练端点及评估参数。推理batch=1，在最大评估参数的完整查询网格上预热5次、测30次。各方案循环交错执行并同步GPU；推理使用相同模型权重。参数面已预计算并缓存，时间不包含首次PDE曲面构建、模型加载、CPU回传、质量计算及绘图。

不同方案使用相同模型结构和输入点数，但边界输入坐标随参数化变化。CPU与Torch双精度连续面求值最大差为 1.332e-15。

## 当前参数化的具体含义与文献关系

平面端面：在端面平面坐标中求解二维逆 Laplace/Winslow 网格方程 $\alpha\mathbf r_{\xi\xi}-2\beta\mathbf r_{\xi\eta}+\gamma\mathbf r_{\eta\eta}=0$，其中 $\alpha=\|\mathbf r_\eta\|^2$、$\beta=\mathbf r_\xi\cdot\mathbf r_\eta$、$\gamma=\|\mathbf r_\xi\|^2$。四条边沿用原来的精确边界及其参数。

连续求值：对稠密 PDE 网格相对原参数面的位移构造张量积三次 B 样条，得到 $\mathbf S_{new}(\xi,\eta)=\mathbf S_{old}(\xi,\eta)+\mathcal I_3[\Delta\mathbf S](\xi,\eta)$，四边位移为零。这是离散 PDE 解的连续插值，而非解析 PDE 解。此次端面均为平面（允许倾斜），因此端面方案不需要曲面 Laplace–Beltrami 求解。run_e 正式实现此前使用201×201端面网格，本次其余八类原型使用101×101。

复杂曲面可选方案：在原解析曲面上用三角形 P1 有限元求 $\Delta_S\xi=0$、$\Delta_S\eta=0$，固定四边参数，数值求逆得到 $\Psi$，再求 $\mathbf S_{new}=\mathbf S_{old}\circ\Psi$。这里改变曲面内部点的分布，不用自由的三维坐标平滑来改变几何外形。数值求逆采用 Clough–Tocher 插值，再用三次样条表示参数位移；其可逆性仍需检查。

方法来源是经典椭圆网格生成与调和曲面参数化，并结合项目现有精确边界、连续插值、批量GPU求值实现。参考 [Floater–Hormann综述](https://www.inf.usi.ch/hormann/parameterization/)；此前提及的 [Schmidt–Singh 2009，Approximate Conformal Parameterization of Point-Sampled Surfaces](https://ftp.cs.toronto.edu/csrg-technical-reports/605/PointSetParam09.pdf) 提供点采样曲面参数化背景，但本原型没有复现其点云近似保角算法，不能据此宣称保角或具有该论文的理论保证。
