# run_e PDE 端面求值复用：离线优化与一致性测试

日期：2026-11-23。未修改正式源码、配置或数据集。仅在独立 Python 进程中替换投影调用，退出进程后失效。

## 测试对象与修改范围

测试当前 run_e 的201×201稠密 PDE 端面连续参数化，深度0.55、1.50、1.52、1.55。四种几何混合组成训练批次。保持精确 Coons 基准面、三次 B 样条位移、全部系数、边界曲线、CCAP和损失公式不变。其他八类边界没有纳入本次计时；其端面不一定共享同一个参数映射，不能直接套用上下端面复用。

1. 上下端面复用（caps）：验证上下端面是同一个 RunPdeCapMap 对象、分别位于z_min/z_max后，只计算一次共同的x/y坐标，分别附加对应z坐标。四个侧面原求值不变。

2. 模板投影复用（both）：由19点中心差分模板显式提供布局，单个面的二维查询从19个缩减至9个，结果按索引还原成原19点顺序；每条棱边的一维查询从19个缩减至3个。上下端面仍复用。所有19个点的网络输出和差分计算均保留。没有把400个中心减少，也没有改用9点三维PDE模板。

只在模板生产端明确提供FDLayout且查询不需要坐标梯度时启用模板复用；任意查询和坐标自动微分回退到未去重的求值路径。此原型针对当前CCAP的固定十二棱边顺序，不应作为未经整合测试的正式通用接口。

batch=2、4个中心的调用计数：六面查询数量912 → 760 → 360，与6×19、5×19、5×9的预期一致。复用不跨训练批次缓存预测值，因此不会使用上一次随机采样的旧坐标。

## 计时方法

硬件：NVIDIA GeForce RTX 4050 Laptop GPU；PyTorch：2.5.1；float32；HMONet参数量：415,215；边界输入网格11×21×11。

每组预热5次，记录30次；交错轮换方案执行顺序，GPU计时前后同步，报告平均值±样本标准差。模型和端面数据驻留GPU；不计首次端面PDE求解、数据加载、固定网格MSE诊断、图表生成及网格质量评估。随机初始化模型用于计算成本测试，不是完整收敛实验。

训练：400个均匀随机中心、0.01中心差分、每中心19个查询，仅归一化PDE损失，包含zero_grad、完整模型前向、损失、反向、梯度裁剪及Adam更新。每个方案相同初始权重和相同查询。

## 一致性验证

- float32、batch=64、400中心：完整网络输出、归一化PDE损失、全部有梯度的模型参数梯度，两个优化版本相对原实现均逐位一致，最大绝对差0。

- float64、batch=4、24中心：上述三项也均逐位一致。

- 401×401密集端面查询包含节点之间位置及四条边：六面求值逐位一致，最大绝对差0。

- 四组普通推理查询（包括完整41×81×41网格）输出均逐位一致。

- float64坐标自动微分：输出逐位一致；一阶导数最大差3.73e-14，二阶导数最大差8.61e-12；对应相对L2误差5.18e-16、2.58e-14。端面复用改变了自动微分累加顺序，属于浮点舍入差异。模板去重没有应用到这种坐标求导场景。

- 正式端面实现、投影后端、模型代码和三维训练配置的SHA-256在测试前后相同（见results.json）。

## 文件与复现

- results.json：原始计时样本、标准差、模型/损失/梯度误差和正式源码哈希。
- path_checks.json：面求值数量与密集端面一致性检查。
- offline/cap_reuse_offline.py：进程内优化原型。
- offline/test_cap_reuse.py：构造/缓存端面，运行验证和计时。
- offline/check_cap_reuse_paths.py：求值数量与密集端面检查。

脚本适用于本机现有项目路径与MGNet环境，测试缓存默认写到C:/Users/24846/tmp/cap_reuse_results。运行时先切换到offline目录，执行test_cap_reuse.py，再执行check_cap_reuse_paths.py。无需覆盖src中的任何文件。

## 建议

值得将这两项作为后续正式优化候选，优先服务batch=64有限差分训练。正式整合前仍应补齐异构几何、非中心差分、其他硬约束模式和自动微分路径的接口回退测试。本次仅验证run_e及当前CCAP、19点中心差分的计算等价性和性能，没有修改参数化，也没有改变其双射保证。
