# 消融实验套件

- `ex1/`：迁移前的全部历史消融实验、模型和评估结果，配置与指纹保持原样。
- `ex2/`：主干几何系数、自注意力、Softplus 激活三项网络结构消融；基线 Jacobian 权重为 `1e-4`。
- `ex3/`：Jacobian 损失与曲边目标插值的 2×2 组合消融。
- `ex4/`：约17.8万参数HMONet下的Jacobian损失与曲边目标插值组合消融。
- `ex5/`：沿用ex3基线训练策略的HMONet参数量消融。
- `ex6/`：沿用ex3基线参数的数据集大小消融，训练子集不落盘。

运行时用 `--experiment-set ex1|ex2|ex3|ex4|ex5|ex6` 选择套件。每套实验独立读取自己的 `baseline/experiment.yaml`、`baseline/evaluate.yaml` 和 `configs/ablation_2d.yaml`，训练、评估及汇总结果也只写入该套件目录。

## 评估输出

消融评估先使用套件内唯一的 `.eval_work/` 临时目录，完成后立即整理到：

```text
experiments/<exN>/eval/<数据集>/<实验短名>/<变体短名>/<随机种子>/<标签>/<网格规模>/<参数值>/
```

临时目录不再创建随机哈希子目录。正式目录对过长的数据集、实验和变体名称使用稳定短名，并在写入前后检查 Windows 经典路径上限的 90%。

只评估指定网格规模时使用 `--evaluate-only --evaluation-grid-shapes 101x101 201x201`；只补指定几何参数时再加 `--evaluation-values 0.04`。未指定 `--force` 时，匹配指纹的训练和评估均直接复用。

每套实验的公共基线训练与评估只保存一份：训练位于 `baseline/<数据集>/...`，评估位于 `eval/<数据集>/base/...`。其他消融实验若检测到与冻结基线完全相同的训练参数，会直接复用这份基线及其匹配的评估结果，不再在各实验目录中重复生成 `base` 结果。
