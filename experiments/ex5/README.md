# Jacobian/SVD屏障超参数消融

基线使用 `w_J=0.01, τ_J=0.02, w_σ=0.05, τ_σ=0.05`，其余训练设置与当前自监督 HMONet 一致。默认数据集为 `air_t_ext_1_500_21_21`。

- `e1_1`–`e1_6`：扫描 Jacobian 屏障权重 `100, 10, 1, 0.1, 0.001, 0.0001`；
- `e2_1`–`e2_6`：扫描 Jacobian 阈值 `0.001, 0.005, 0.01, 0.05, 0.1, 0.2`；
- `e3_1`–`e3_6`：扫描 SVD 屏障权重 `100, 10, 1, 0.1, 0.01, 0.001`；
- `e4_1`–`e4_5`：扫描 SVD 阈值 `0.001, 0.005, 0.01, 0.1, 0.2`。

最后一组按给定的五个非基线阈值建立；`0.05` 是基线阈值，故不重复训练。

```bash
python scripts/experiments/run.py ex5 baseline all --dataset air_t_ext_1_500_21_21 --seed 20261030 --grids 101 201 401 --values 0.62 0.65 --tag v1
```
